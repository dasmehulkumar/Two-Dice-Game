<h1 align="center">🎲 Two Dice Game</h1>

<p align="center">
  A simple and fun two-player dice game built using web technologies.
</p>

<hr>

<h2>🚀 Project Overview</h2>
<p>
The <b>Two Dice Game</b> is an interactive project where two players roll dice, and the system determines the winner based on the dice values.
</p>

<p>It helps in understanding:</p>
<ul>
  <li>DOM Manipulation</li>
  <li>Random Number Generation</li>
  <li>Basic Game Logic</li>
</ul>

<hr>

<h2>🎮 How It Works</h2>
<ul>
  <li>Two dice are rolled randomly 🎲🎲</li>
  <li>Each player gets one dice value</li>
  <li>The values are compared</li>
  <li>The winner is displayed instantly</li>
</ul>

<table>
  <tr>
    <th>Condition</th>
    <th>Result</th>
  </tr>
  <tr>
    <td>Player 1 &gt; Player 2</td>
    <td>🏆 Player 1 Wins</td>
  </tr>
  <tr>
    <td>Player 2 &gt; Player 1</td>
    <td>🏆 Player 2 Wins</td>
  </tr>
  <tr>
    <td>Equal Values</td>
    <td>🤝 It's a Tie</td>
  </tr>
</table>
